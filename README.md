# Автоматизация расчёта параметров электронных компонентов печатных плат

## Описание проекта

Python-приложение для автоматизации обработки спецификаций электронных плат, расчёта характеристик электронных компонентов и подготовки данных для технологической документации.

Программа анализирует Excel-файл со спецификацией платы, сопоставляет компоненты с отдельным справочником и рассчитывает количественные показатели, необходимые для подготовки технологического процесса сборки и монтажа.

Проект создан для сокращения времени ручной обработки технической документации, уменьшения количества рутинных операций и повышения точности расчётов.

## Основные возможности

- Загрузка спецификации печатной платы из Excel.
- Загрузка справочника электронных компонентов.
- Автоматическое сопоставление компонентов по обозначениям и библиотечным идентификаторам.
- Подсчёт общего количества электронных компонентов.
- Расчёт общего количества выводов компонентов.
- Классификация компонентов по типу выводов:
  - планарные;
  - штырьковые;
  - ПМИ.
- Подсчёт микросхем и их выводов.
- Определение компонентов, требующих формовки и лужения.
- Учёт операций флюсования и приклеивания элементов.
- Возможность добавления компонентов вручную.
- Формирование подробного отчёта о результатах анализа.
- Автоматическое заполнение предусмотренных ячеек Excel-шаблона технологического процесса.

## Используемые технологии

- **Python** — основная логика приложения.
- **Pandas** — чтение, обработка и анализ табличных данных.
- **OpenPyXL** — работа с Excel-файлами и заполнение технологической документации.
- **Tkinter** — графический интерфейс пользователя.
- **Regular Expressions (re)** — инструменты обработки текстовых данных.

## Принцип работы

1. Пользователь выбирает Excel-файл со спецификацией печатной платы.
2. Загружает Excel-файл со справочником компонентов.
3. Программа обрабатывает обозначения компонентов и выполняет поиск соответствующих записей в справочнике.
4. На основании найденных характеристик рассчитывает количество компонентов, выводов и технологических операций.
5. При необходимости пользователь может добавить компоненты вручную.
6. Программа формирует отчёт с результатами анализа.
7. Рассчитанные значения используются для заполнения соответствующих полей Excel-шаблона технологического процесса.

## Структура входных данных

### Спецификация печатной платы

Excel-файл должен содержать данные о компонентах, включая поля:

| Столбец | Назначение |
|---|---|
| `Designator` | Обозначение компонента |
| `Companent_key` | Идентификатор или ключ компонента |

### Справочник компонентов

Справочник содержит характеристики электронных компонентов:

| Столбец | Назначение |
|---|---|
| `LibRef` | Библиотечное обозначение |
| `количество выводов` | Количество выводов компонента |
| `тип выводов` | Тип выводов |
| `формовка` | Признак необходимости формовки |
| `лужение` | Признак необходимости лужения |
| `приклеивание прокладки` | Признак операции приклеивания прокладки |
| `приклеивание к плате` | Признак приклеивания компонента к плате |
| `микросхема` | Признак принадлежности к микросхемам |
| `соединитель` | Признак соединителя |


## Результат работы

Программа позволяет получить структурированные количественные данные о составе печатной платы и использовать их для заполнения технологической документации.

Автоматизация особенно полезна при работе со сложными электронными платами, содержащими большое количество компонентов, когда ручной подсчёт требует значительных временных затрат.

## Цель проекта

Проект демонстрирует применение Python для решения реальной инженерной задачи: автоматизации обработки технической документации, работы с базами данных компонентов, расчёта технологических параметров и интеграции результатов с Excel.
